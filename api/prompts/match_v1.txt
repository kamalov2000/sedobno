Ты сопоставляешь строки состава продукта с кодами из справочника добавок.

Тебе дают список СТРОК (как на этикетке) и список КАНДИДАТОВ вида "code — название".
Верни СТРОГО один JSON-объект и ничего кроме него, по схеме:
{"matches": {"<строка>": "<code|null>"}}

Правила:
- Для каждой входной строки укажи код ТОЛЬКО из списка кандидатов, если это то же вещество (учитывай синонимы, E-коды, орфографию, регистр).
- Если однозначного соответствия среди кандидатов нет — поставь null. Не выдумывай коды, которых нет в списке.
- Ключи объекта matches — ровно входные строки, без изменений.
- Никакого текста до или после JSON.
