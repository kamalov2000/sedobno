# Проверка правил на группе продуктов, где сахар стоит первым

Повод — Kinder Bueno White с баллом 85 в матрице этикеток. Подкручивать правила под один
продукт нельзя: так балл превращается в набор частных случаев, которые невозможно
объяснить человеку. Поэтому сначала — группа.

## Как проверено

Двенадцать реальных составов, где сахар (или сироп/патока) в первых трёх позициях,
прогнаны через фазы 2–4 пайплайна в mock-режиме: нормализация → скоринг → объяснение,
без вызовов модели и без денег. Фикстуры лежат в `testdata/sugar_first/`, прогон:

```bash
LLM_PROVIDER=mock go run ./cmd/evalpipe --dir ../testdata/sugar_first
```

## Результат

| Продукт | Балл | Что сняло балл |
|---|---|---|
| Kinder Bueno White | 85 | сахар −15 |
| Молочный шоколад | 85 | сахар −15 |
| Сгущёнка | 85 | сахар −15 |
| Йогурт с сахаром | 85 | сахар −15 |
| Халва | 85 | сахар −15 |
| Зефир | 85 | сахар −15 |
| Детские хлопья | 85 | сахар −15 |
| Печенье сахарное | 82 | сахар −15, сорбат калия −3 |
| Батончик мюсли | 80 | сахар −15, пальмовое масло −5 |
| Газировка | 79 | сахар −15, ортофосфорная кислота −3, колер −3 |
| Карамель | 75 | сахар −15, тартразин −10 |
| Мармелад | 65 | сахар −15, два красителя по −10 |

**Семь из двенадцати получают ровно 85.** Это не особенность батончика, а устройство
правил: на сахар есть ровно одна реакция — фиксированные −15 за «сахар в первых трёх
позициях», — и когда больше штрафовать нечего, любой сладкий продукт с чистым остальным
составом приходит к 85. Зефир, который состоит из сахара почти целиком, получает столько
же, сколько сгущёнка, где сахар третьим.

Разброс 65–85 создают не сладость, а КРАСИТЕЛИ: мармелад ниже карамели только потому, что
в нём два штрафных красителя, а не потому, что он слаще.

## Что с этим можно сделать (решение за владельцем)

Три варианта, от самого дешёвого:

1. **Ничего не менять в баллах, поправить подпись.** Балл честно называется «оценка
   состава по правилам Съедобно» — то есть он про добавки, а не про сахар. Можно сказать
   это прямее на экране продукта с сахаром в первых позициях: «85 — по добавкам; сахар в
   составе первый». Ноль риска, но и ноль изменений в самом балле.
2. **Градация штрафа по позиции.** Сейчас −15 одинаковы для сахара на первом и на третьем
   месте. Разнести (условно 25 / 18 / 12) — правило остаётся одним, объяснимым и
   применимым ко всей группе; зефир опустится ниже сгущёнки, что соответствует смыслу.
3. **Считать по пищевой ценности.** Мы уже читаем таблицу: сахара в граммах на 100 г — это
   факт, а не эвристика позиции. Самый честный вариант и самый дорогой: нужен порог,
   калибровка и решение, что делать, когда таблица не прочиталась (у 6 из 23 кадров
   матрицы её в кадре не было).

Рекомендация: 1 + 2. Первое снимает недоумение сразу и ничего не ломает, второе делает
правило соразмерным, оставаясь одним правилом на всю группу. Третье — отдельная работа,
и её стоит начинать, только когда наберётся статистика по прочитанным таблицам.

**Само по себе изменение не сделано:** это решение о том, что продукт «плохой», а такие
решения не принимаются правкой коэффициента в обход владельца.
