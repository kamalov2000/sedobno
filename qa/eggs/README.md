# Контролируемая серия: разрезанные яйца

Пять снимков, по которым проверяется не арифметика (она закрыта тестами), а **счёт срезов
на реальном фото**. Именно он и подвёл: на снимке с четырьмя половинками модель увидела
три — одна лежала белком вверх и почти сливалась с тарелкой.

## Что снять

Пять кадров, имена обязаны быть точно такими — по имени скрипт берёт ожидаемое количество,
и подогнать его задним числом нельзя:

| Файл | Что на кадре | Ждём |
|---|---|---|
| `2_halves.jpg` | два среза одного варёного яйца, желтком вверх | 78 ккал |
| `3_halves.jpg` | три среза (полтора яйца), все желтком вверх | 117 ккал |
| `4_halves.jpg` | четыре среза (два яйца), все желтком вверх | 156 ккал |
| `4_halves_white_up.jpg` | четыре среза, ОДИН из них перевёрнут белком вверх | 156 ккал |
| `2_whole.jpg` | два целых варёных яйца, не разрезанных | 156 ккал |

## Как снять, чтобы серия была контролируемой

- **Один фон и один свет на все пять кадров.** Тарелка, стол и освещение не меняются —
  иначе разброс результата нельзя будет отнести к количеству срезов.
- **Ничего, кроме яиц, в кадре.** Гарнир и приборы добавляют модели работы и смешивают
  причины: мы проверяем счёт яиц, а не разбор тарелки.
- **Срезы не накладываются друг на друга** — кроме `4_halves_white_up.jpg`, где сложность
  и есть предмет проверки (перевёрнутый срез).
- **Снимать сверху**, кадр целиком занят тарелкой, телефон держать ровно.
- **Одна серия — один заход.** Пересняли один кадр иначе — переснимите все: сравнимость
  важнее удобства.

## Как прогнать

Положить снимки в эту папку, затем на проде:

```bash
cd /opt/sostav && bash scripts/eggs_series.sh qa/eggs
```

Каждый кадр уходит через боевой `POST /api/meals` **дважды**: один прогон не отличает
«сосчитала верно» от «повезло», а расхождение двух прогонов на одном кадре — и есть мера
надёжности счёта.

Скрипт печатает по строке на прогон: что на фото, что насчитала модель, ккал яичного
компонента, ожидаемое значение, итог приёма, уверенность, пометку «проверьте количество»,
время и стоимость. Стоимость серии — примерно 10 разборов × ~3,2 ₽ ≈ 32 ₽.

## Как читать результат

- **Количество совпало в обоих прогонах** — счёт надёжен на этом кадре.
- **Количество разошлось между прогонами** — кадр неоднозначен для модели; это допустимо
  ТОЛЬКО при пометке «проверьте количество» (колонка «проверить» = да) и правке числа
  тапом по чипсу «Половинка».
- **Количество стабильно неверно** — дефект счёта, а не разброса; нужен разбор кадра.

Арифметика при этом не обсуждается: половинка стоит ровно половину яйца, и 2 / 3 / 4
половинки обязаны давать 78 / 117 / 156 ккал при правильно сосчитанном количестве.
